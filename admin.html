통계 저장소가 아직 연결되지 않았어요

아래 순서대로 한 번만 설정하면 방문 통계가 쌓이기 시작합니다.

  1. supabase.com에 가입하고 새 프로젝트를 만듭니다 (지역: Seoul, 무료 플랜).
  2. 왼쪽 SQL Editor에 저장소의 supabase/setup.sql 내용을 붙여넣고, 맨 아래 이메일을 본인 이메일로 바꾼 뒤 Run.
  3. Authentication → Users → Add user에서 같은 이메일과 비밀번호로 관리자 계정을 만듭니다 (Auto Confirm 체크).
  4. Authentication → Sign In / Providers에서 Allow new users to sign up을 끕니다.
  5. Project Settings → API의 Project URL과 anon(publishable) key를 config.js에 넣습니다.
