# 가치작명소 (gachi-naming)

작명 앱을 쓰려다 유료라서, **무료로 작명할 수 있는 앱**을 직접 만들었습니다. 성명학(사주·오행·음양·81수리·발음오행·자원오행·항렬자) 기반으로 이름을 짓습니다.

- 앱 주소: https://gyusootory.github.io/gachi-naming/
- ① **아이 생일을 넣으면 이름을 추천**해 줘요
- ② **원하는 이름에 맞는 한자**도 찾아 줘요
설치 없이 `index.html`을 브라우저로 열면 동작합니다(인터넷 연결 시 글꼴만 추가로 받음).

## 주요 기능
1. **① 이름 추천 탭**: 성씨·성별·양력/음력 생년월일시(윤달, 시간 모름, 경도 보정)와 항렬자(위치 지정)를 넣으면 100점 만점으로 평가한 이름을 **점수 높은 순서대로 5개씩 페이지**로 보여 줍니다(같은 조건이면 언제나 같은 순서). 페이지 번호나 `다음 5개 보기`로 넘겨 봅니다.
2. **② 이름으로 한자 찾기 탭**: 원하는 한글 이름(예: 서윤)을 넣으면 가능한 모든 한자 조합을 성명학 점수순으로 보여주고, 음절별 후보 한자(훈·음·원획·자원오행)도 함께 보여줍니다.
3. **③ 내 이름 풀이 탭**: 지금 이름·한자·생년월일로 사주 기준 점수(참고용)와 장단점을 보여 주고, 같은 사주의 개명 후보와 비교한 뒤 `개명 후보 보기`로 ① 탭 추천까지 이어집니다. 입력한 이름은 서버로 보내지 않습니다.
4. **④ 저장한 이름 탭**: 카드의 `♡ 저장`을 누르면 이 기기·브라우저(localStorage)에 보관되고, 저장 탭에서 다시 보거나 공유·삭제할 수 있습니다.

세 기능은 탭으로 나뉘어 있고 각 탭이 자기 입력칸을 따로 가집니다. 점수 배점과 계산 규칙은 화면 아래 **작명 기준** 접이식 안내에서 볼 수 있습니다.

공유용 단일 파일: `dist/가치작명소.html` (`python3 tools/bundle.py`로 다시 만듦)

## 공유·설치
- 화면 오른쪽 위 **앱 공유** 버튼: 앱 주소를 카카오톡 등으로 보냅니다(공유 창이 없으면 클립보드 복사).
- 이름 카드의 **이 이름 공유하기**: 이름·한자·뜻 풀이·점수를 글로 묶어 보냅니다.
- `docs/` 폴더는 홈 화면에 설치되는 웹앱(PWA)입니다. GitHub Pages(브랜치 `/docs` 폴더)나 아무 정적 호스팅에 올리면 `https://…` 주소로 열리고, 휴대폰에서 ‘홈 화면에 추가’하면 앱처럼 실행되며 오프라인에서도 열립니다.
- `dist/가치작명소-웹앱.zip`은 `docs/` 폴더를 압축한 것입니다(정적 호스팅에 끌어다 놓기용).

## 방문 통계 · 관리자 화면
- `analytics.js`가 방문·기능 사용을 익명으로 Supabase `events` 표에 기록합니다. 생년월일·시각·성씨는 보내지 않습니다.
- `admin.html`(배포 주소 `/admin.html`)에서 관리자 이메일로 로그인하면 순 방문자, 일별 추이, 이용 흐름, 기능별 사용, 인기 검색 이름, 기기·유입 경로를 볼 수 있습니다. `admin.html?demo`는 예시 데이터 미리보기입니다.
- 설정: `supabase/setup.sql` 실행 → 관리자 계정 생성·회원가입 끄기 → `docs/config.js`에 Project URL과 anon(publishable) 키 입력.

## 한자 추가하는 법
**관리자 화면에서 (권장, 코드 수정 없음)**
1. 처음 한 번: Supabase SQL Editor에서 `supabase/hanja_admin.sql` 실행 (안의 `admin@example.com`을 관리자 이메일로 변경)
2. 관리자 화면 → '한자 추가 · 앱 공지'에 한자 한 글자 입력 → 획수·부수·오행·소리 자동 채움 → 뜻(훈) 입력 → '앱에 추가'
   - 제보 목록의 '한자 추가' 버튼을 누르면 제보 내용이 자동으로 채워짐
3. 사용자가 앱을 새로 열면 한자 목록에 합쳐지고, 상단에 '추가된 한자' 한 줄 공지가 표시됨(✕로 닫으면 그 날짜 공지는 다시 안 보임)
4. 제보 '처리 완료'도 서버(report_done 표)에 저장되어 휴대폰·PC 어디서나 같게 보임

**코드로 (기본 데이터에 영구 반영)**
1. `tools/hanja_source.txt`의 해당 소리 줄에 `한자훈` 추가, `tools/meaning_source.txt`에 뜻 풀이 한 줄 추가
2. `tools/hanja_updates.json`에 날짜와 글자 추가 → 앱 상단 공지에 함께 표시
3. `python3 tools/build_data.py <unihan.db>` → `python3 tools/bundle.py` (관리자용 한자 사전 `hanja-dict.js`도 함께 생성)

## 이름 뜻 풀이
추천 카드마다 이름 전체의 뜻을 한 문장으로 풀어 줍니다(예: “기쁨을 나누는 밝은 마음과 옥빛처럼 맑은 광채를 함께 지닌 사람이 되라는 뜻을 담았습니다.”). 한자별 풀이 키워드는 `tools/meaning_source.txt`에서 고칠 수 있습니다.

## 파일 구성
- `index.html` 화면과 스타일
- `engine.js` 사주(입춘·12절기 태양황경, 일주 율리우스적일), 용신(억부), 81수리, 발음/자원오행, 점수 계산
- `app.js` 추천·찾기 화면 로직
- `hanja-data.js` 이름용 한자 552자 + 성씨 115개(복성 포함) — `tools/build_data.py`로 생성
- `korean-lunar-calendar.min.js` 음력↔양력 변환(KASI 기준, MIT 라이선스, npm `korean-lunar-calendar` 0.4.0)

한자 원획수는 Unicode Unihan의 강희자전 부수·잔획 데이터로 계산합니다(부수 본래 획수 + 나머지 획수).
데이터 재생성: `python3 tools/build_data.py <unihan.db>` (npm `cjk-unihan` 패키지의 `data/unihan.db`).

## Firebase 자동 배포
- `docs/` 폴더가 바뀐 채로 GitHub에 올라가면 `.github/workflows/firebase-deploy.yml`이 **gachi-naming.web.app**에 자동 배포합니다.
- 처음 한 번: 저장소 Settings → Secrets and variables → Actions → `FIREBASE_SERVICE_ACCOUNT`에 Firebase 서비스 계정 JSON 키 전체를 붙여넣기
- 설정(`firebase.json`): 공개 폴더 `docs`, html·js는 항상 최신 확인(no-cache), 이미지는 하루 보관
