# 오행 작명소

사주(생년월일시)·오행·음양·81수리(원형이정)·발음오행·자원오행·항렬자를 계산해 이름과 한자를 추천하는 웹앱입니다.
설치 없이 `index.html`을 브라우저로 열면 동작합니다(인터넷 연결 시 글꼴만 추가로 받음).

## 주요 기능
1. **① 이름 추천 탭**: 성씨·성별·양력/음력 생년월일시(윤달, 시간 모름, 경도 보정)와 항렬자(위치 지정)를 넣으면 100점 만점으로 평가한 이름을 5개씩 추천합니다. `다른 이름 5개 보기`를 누를 때마다 아직 보여주지 않은 상위 후보 5개를 새로 뽑습니다.
2. **② 이름으로 한자 찾기 탭**: 원하는 한글 이름(예: 서윤)을 넣으면 가능한 모든 한자 조합을 성명학 점수순으로 보여주고, 음절별 후보 한자(훈·음·원획·자원오행)도 함께 보여줍니다.
두 기능은 탭으로 나뉘어 있고 각 탭이 자기 입력칸을 따로 가집니다. 점수 배점과 계산 규칙은 화면 아래 **작명 기준** 접이식 안내에서 볼 수 있습니다.

공유용 단일 파일: `dist/오행작명소.html` (`python3 tools/bundle.py`로 다시 만듦)

## 점수 (100점)
| 항목 | 배점 | 내용 |
|---|---|---|
| 원형이정 81수리 | 40 | 원·형·이·정격 각 10점(길 10 / 반길 5 / 흉 0) |
| 자원오행 | 25 | 이름 한자 오행이 사주 용신·부족 오행을 채우는지 + 성→이름 상생 흐름 |
| 발음오행 | 15 | 초성 오행의 상생 |
| 음양 | 10 | 획수 홀짝 조화 |
| 삼원오행 | 10 | 천·인·지격 수리오행 상생 |

## 파일 구성
- `index.html` 화면과 스타일
- `engine.js` 사주(입춘·12절기 태양황경, 일주 율리우스적일), 용신(억부), 81수리, 발음/자원오행, 점수 계산
- `app.js` 추천·찾기 화면 로직
- `hanja-data.js` 이름용 한자 552자 + 성씨 115개(복성 포함) — `tools/build_data.py`로 생성
- `korean-lunar-calendar.min.js` 음력↔양력 변환(KASI 기준, MIT 라이선스, npm `korean-lunar-calendar` 0.4.0)

한자 원획수는 Unicode Unihan의 강희자전 부수·잔획 데이터로 계산합니다(부수 본래 획수 + 나머지 획수).
데이터 재생성: `python3 tools/build_data.py <unihan.db>` (npm `cjk-unihan` 패키지의 `data/unihan.db`).

## 벤치마킹한 서비스 (앱스토어 소개·공개 소개글 기준)
| 서비스 | 참고한 기능 |
|---|---|
| 이름다움 | 사주 보완형 추천, 한자별 의미 풀이, 만세력·오행 표시 |
| 작명家(협회공인 작명어플) | 한글 이름 입력 → 한자 자동 추천 |
| 베베네임 | 출생 정보 없이도 이름 미리 짓기 → '사주 반영' 선택 옵션 |
| 작명신 네이머 | 만세력·통계 기반 인기 이름 후보 |
| 넴유베(Name Your Baby) | 초성 발음오행 체크 |
| 명작명 이름짓기 | 음령오행·자원오행·원형이정 4격 자동 계산, 기기 밖으로 정보 미전송 |
| 아기이름 작명도우미 | 단계별 셀프 작명 흐름 |
| 네임소프트 무료작명소 | 무료 성명 감명(4격 풀이) |
| 브런치 '한자 아기 이름 작명 도우미' 연재 | 자원오행 표, 인명용 한자 확인 안내 |
| 크몽 전문가 작명 서비스 | 항렬자·불용문자 등 작명가 상담 항목 |
